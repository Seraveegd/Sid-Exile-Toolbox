偵測點座標與顏色定位

本功能需要先設定各偵測點的座標與顏色，否則對應檢測功能會自動停用。

請使用快捷鍵 Win + C 校正偵測點位置與顏色。 若未設定，已啟用的偵測類型將在啟動時自動關閉。
  • 1：人物上方血條偵測點 (無血顏色)
  • 2：人物上方血條返角偵測點 (無血顏色)
  • 3：右下魔力球偵測點 (滿魔顏色)
  • 4：左下藥劑欄上方時間黑色區域
  • 5：Enter 對話框1 黑色域
  • 6：Enter 對話框2 黑色域
  • 7：人物上方混傷穿透血條偵測點
  • 8：人物上方混傷穿透返角偵測點
  • 9：左下血球池偵測點 (滿血顏色)

提醒：若偵測點尚未設定，系統會自動關閉高級喝水功能，請先完成偵測點校正。

偵測喝水參數
請使用快捷鍵 F10 開關高級喝水模式。搭配 Win + C 重新校正座標與顏色偵測點。
例：只喝第1罐請輸入 1；喝2瓶輸入 12；挖礦補血+開燈輸入 16。
